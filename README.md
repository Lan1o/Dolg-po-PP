# CampusThesis

CampusThesis — веб-платформа для управления процессом написания и защиты выпускных квалификационных работ (ВКР). Сервис обеспечивает полный цикл взаимодействия: от выбора темы из каталога до загрузки этапов работы и получения отзывов от научного руководителя.

## Стек технологий

Backend:
- Python 3.12
- Django 5.1 + Django REST Framework (DRF)
- SQLite
- JWT (djangorestframework-simplejwt) для аутентификации
- drf-spectacular (Swagger/OpenAPI)

Frontend:
- Vue 3 (Composition API)
- Vite
- Vue Router
- Bootstrap 5
- Fetch API

## Реализованный функционал

1. Многоролевая модель: Студент, Руководитель, Администратор (у каждой роли свой интерфейс).
2. Каталог тем: поиск по ключевым словам и 4 фильтра (направление, руководитель, статус, теги).
3. Личные кабинеты: история действий, список заявок, уведомления.
4. Цепочка статусов: для заявок (Подана, На рассмотрении, Одобрена/Отклонена) и для этапов ВКР (Не начат, На проверке, Одобрен/Доработать).
5. Загрузка файлов: студент прикрепляет файлы к этапам, руководитель скачивает их.
6. Уведомления: колокольчик со счётчиком в шапке, страница со списком событий (подача заявки, отзыв, смена статуса).
7. Адаптивность: корректное отображение на десктопе и мобильных устройствах (Bootstrap-сетка, бургер-меню).
8. Swagger: интерактивная документация API с возможностью тестирования эндпоинтов.

## Инструкция по запуску

### Предварительные требования
- Python (версия 3.11 или 3.12). Версия 3.15 пока не поддерживается некоторыми библиотеками.
- Node.js (версия 18 или выше) и npm.

### Запуск бэкенда (Django)

Откройте терминал в корневой папке проекта:

```
cd backend

# Создаем и активируем виртуальное окружение
python -m venv .venv
.venv\Scripts\activate        # Для Windows
# source .venv/bin/activate   # Для Mac/Linux

# Устанавливаем зависимости
pip install -r requirements.txt

# Применяем миграции базы данных
python manage.py migrate

# Наполняем базу демо-данными
python manage.py seed

# Создаем суперпользователя для доступа в админку Django
python manage.py createsuperuser
# (Вас попросят ввести логин, email и пароль. Рекомендуется использовать логин admin и пароль admin)

# Запускаем сервер
python manage.py runserver
Бэкенд будет доступен по адресу: http://localhost:8000

# Важно: бэкенд является REST API и не имеет корневой страницы. При переходе на http://localhost:8000/ вы увидите ошибку 404 — это нормально. Рабочие адреса указаны ниже:
* Документация API (Swagger): http://localhost:8000/api/docs
* Проверка работоспособности API: http://localhost:8000/api/health
* Панель администратора: http://localhost:8000/admin
```

### Запуск фронтенда (Vue + Vite)
Откройте второй терминал и перейдите в папку фронтенда:

``` 
cd frontend

# Устанавливаем зависимости
npm install

# Запускаем сервер разработки
npm run dev
Фронтенд будет доступен по адресу: http://localhost:5173
```

### Ключевой сценарий работы
1. Студент входит в систему, открывает Каталог тем, использует поиск и фильтры, находит подходящую тему и подает заявку.
2. Руководитель видит новую заявку в своем Инбоксе, одобряет её или отклоняет с комментарием.
3. При одобрении система автоматически создает ВКР и 7 этапов (План, Глава 1, Глава 2, Полный текст, Нормоконтроль, Предзащита, Защита).
4. Студент загружает файл на первый этап. Статус этапа меняется на "На проверке".
5. Руководитель получает уведомление, скачивает файл, проверяет его и оставляет отзыв ("Одобрено" или "Доработать").
6. Если этап одобрен, следующий этап автоматически переходит в статус "В работе".
7. Все действия сопровождаются уведомлениями.
