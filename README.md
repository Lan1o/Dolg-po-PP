# Проект для долга по пп

Платформа управления выпускными квалификационными работами.

## Стек
- Backend: Python 3.12+, Django 5, Django REST Framework, SQLite
- Frontend: Vue 3, Vite, Bootstrap 5
- Auth: JWT (djangorestframework-simplejwt)

## Структура
- backend/ — Django-проект
- frontend/ — Vue + Vite
- docs/ — документация, ER-диаграмма, скриншоты
